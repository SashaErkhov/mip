# Проект - Моделирование информационных процессов
## ТЗ
Обеспечить переход однозвенного маятника в заданное положение за заданное время с использованием линеаризации обратной связью и интерполяцией полиномом пятого порядка (упражнение 9.5 из книжки Modern Robotics)
## Решение
За основу взят маятник с двумя звеньями
### Линеаризация обратной связью
Здесь ничего не поменялось кроме якобиана. Также считается не обратная матрица, а псевдообратная, так как матрица перестала быть квадратной
### Полином пятого порядка
Изначально был реализован полином 3го порядка, но у него есть проблема с резкостью - в начале слишком сильный "толчок". Добавляются 2 условия на вторую производную: dds(0)=dds(T)=0
