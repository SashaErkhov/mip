# Проект - Моделирование информационных процессов
## ТЗ
Обеспечить переход однозвенного маятника в заданное положение за заданное время с использованием линеаризации обратной связью и интерполяцией полиномом пятого порядка (упражнение 9.5 из книжки Modern Robotics)
## Решение
За основу взят маятник с одним звеном за 2025 год
### Полином пятого порядка
Изначально был реализован полином 3го порядка(в двузвенном маятнике), но у него есть проблема с резкостью - в начале слишком сильный "толчок". Добавляются 2 условия на вторую производную: dds(0)=dds(T)=0
## Линеаризация обратной связью
Уже было реализовано в коде, я практически ничего не изменил. Только теперь ошибка считается не до конечной точки а до точки высчитанной по полиному.
